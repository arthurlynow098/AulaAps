# AulaAps

## Sobre o projeto

Estudo de formas geométricas com C# e Windows Forms, desenvolvido para .NET Framework 4.7.2. Inclui classes de circunferência, quadrado, retângulo e triângulos.

## Como explorar

No Windows, abra a solução dentro de `SoFormasAps/SoFormasAPS` no Visual Studio com suporte a .NET Framework 4.7.2 e desenvolvimento desktop. Compile e execute o projeto WfaFormas.
